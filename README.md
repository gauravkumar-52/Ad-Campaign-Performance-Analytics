# Ad Campaign Performance Analytics

## Project Overview
Analysis of 1,143 digital advertising records using Python/Pandas and Power BI to evaluate campaign, demographic, and interest-level performance.

## Tools
- Python (Pandas, statistical analysis)
- Power BI
- CSV
- Exploratory statistics (Welch's t-test)

## Key Analysis
- Data cleaning and KPI engineering
- CTR, CPC, CPM, Conversion Rate, Approval Rate
- Conversion Efficiency (Approved Conversions / Spend)
- Cost per Approved Conversion
- Campaign, age, gender, and interest segmentation
- Exploratory Welch's t-test for campaign comparison

## Important Metric Note
This project does **not** calculate true ROAS because the dataset does not contain revenue. Conversion Efficiency is used instead: Approved Conversions / Spend.

## Files
- `ad_campaign_analytics.ipynb` — Python analysis
- `KAG_conversion_data.csv` — source dataset
- `ad_campaign_processed.csv` — processed data
- `campaign_summary.csv`, `age_summary.csv`, `gender_summary.csv`, `interest_summary.csv` — summary outputs
- `Ad_Campaign.pbix` — Power BI dashboard
- `AdCampaign_Interview_PrepKit.pdf` — interview preparation material
